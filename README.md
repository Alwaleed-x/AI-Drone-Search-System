
# 🛰️ AI Drone Search System

An Intelligent Search and Rescue System to Detect Lost Humans in the Desert

---

## 📌 Project Overview
This project was developed as a graduation capstone to address the challenges of search and rescue in desert environments. By combining AI-driven object detection with drone technology, the system is capable of identifying missing persons in vast, hard-to-reach desert areas using aerial and thermal imagery.

---

## 🎯 Objectives
- Investigate similar AI-based search and rescue systems
- Design and test object detection algorithms for identifying humans from aerial imagery
- Develop and evaluate a machine learning model using YOLOv3 and CNN
- Utilize drones and thermal imaging for real-time surveillance and detection

---

## 🛠️ Technologies & Tools
- **Programming Language:** Python
- **AI Frameworks:** TensorFlow, Keras
- **Detection Models:** YOLOv3, CNN
- **Dataset:** COCO (Common Objects in Context)
- **Hardware Concept:** Drone equipped with camera and thermal sensors

---

## 🧠 System Workflow
1. **Capture Image** – Using drone-mounted cameras and thermal sensors.
2. **Image Processing** – Clean and enhance images to prepare for detection.
3. **Object Detection** – Use AI (YOLOv3) to detect potential humans.
4. **Location Identification** – Estimate coordinates using georeferencing/GPS.

---

## 📊 Results
- Both YOLO and CNN achieved high accuracy.
- YOLO had a clear advantage in speed and real-time detection.
- System is suitable for live deployment in rescue missions.
